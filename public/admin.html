Como funciona

O bot entra no chat do canal informado abaixo e escuta por comandos !votar N (ou !vote N), onde N é o número da opção na categoria marcada como "ativa para o chat". Cada espectador vale 1 voto, identificado pelo ID da conta Twitch dele (não dá pra votar duas vezes trocando de nome).

Pra gerar o token OAuth do bot: crie ou use uma conta Twitch pro bot, acesse twitchtokengenerator.com, gere um token do tipo "Bot Chat Token" (escopos chat:read e chat:edit) e cole abaixo, junto com o "oauth:" no início (se vier separado).
